# Sandro Rukhadze — Portfolio

Personal portfolio website. Hand-coded (HTML / CSS / JS), no framework.

**Live:** https://anagv.netlify.app

## Structure
- `index.html` — page markup
- `styles.css` — design & layout (warm, earthy palette)
- `script.js` — scroll reveals, spotlight cursor, nav
- `hero.jpg` — hero portrait

## Editing
Open the folder in a code editor, change the files, then commit & push —
Netlify redeploys automatically.

Preview locally: open `index.html`, or run `python -m http.server` in this folder.
